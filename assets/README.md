# Logo assets

© Industrial AI Lab, all rights reserved. These files are **not** covered by the CC BY 4.0 licence that applies to the text in this repository. You may use them unmodified to refer to the lab, for example when citing our work or linking to it.

The mark is a hexagon, the outline of a hex nut, with two upward chevrons cut out of it. The hexagon stands for industry; the chevrons stand for continuous improvement and for flight.

| File | Use |
| --- | --- |
| `logo.svg` | Mark, primary colour |
| `logo-mono.svg` | Mark, single colour (`currentColor`), for one-colour use |
| `logo-wordmark.svg` | Mark and lab name |
| `avatar-500.png`, `avatar-1024.png` | Square avatar with padding for rounded crops |
| `banner-light.svg`, `banner-dark.svg` | README banners for light and dark themes |

## Colours

| Role | Light theme | Dark theme |
| --- | --- | --- |
| Mark and title | `#0F3D68` (11.1:1 on white) | `#E6EDF3` (16.0:1 on `#0D1117`) |
| Accent rule | `#B35900` (4.8:1 on white) | `#E69F00` (8.4:1 on `#0D1117`) |

The mark uses one colour, so it does not rely on colour to be read. The accent (orange) and the primary (blue) can be told apart by people with all common forms of colour blindness. All text and graphics meet WCAG 2.2 AA contrast.

Typeface: IBM Plex Sans (SIL Open Font License), converted to outlines.
